Privacy Policy – Biladi Page Webhook Bot

Last updated: October 9, 2026

1. Introduction

This Privacy Policy explains how Biladi Page Webhook Bot ("the App", "we", "us") handles information when it is used with Facebook Pages. The App is designed to monitor comments on a Facebook Page and perform automated engagement actions, such as replying to or liking comments.

By using the App, or by interacting with a Facebook Page that uses the App, you acknowledge the practices described in this policy.

2. Information We Access

Only when necessary for the App's functionality, the App may access the following information through the Facebook Pages API and Webhooks:

  • Page ID
  • Post ID
  • Comment ID
  • Comment text
  • Publicly visible user name

No passwords, payment information, or private messages are collected by the App, and it does not collect any other non-public personal information.

3. How We Use Information

The information listed above is used only to provide automated page engagement features, including:

  • Detecting new comments on Page posts
  • Sending automated replies to comments
  • Managing interaction with comments, such as liking them

We do not use this data for any other purpose.

4. Facebook Pages API and Webhooks

The App uses the Facebook Pages API and Webhooks provided by Meta. Webhooks notify the App when an event occurs on a connected Page, such as a new comment. The App then uses the Pages API to perform the configured action, such as posting a reply or liking the comment.

The App uses the Facebook Pages API and Webhooks only for automated page engagement features. Access is limited to the Pages that the Page administrator has connected to the App and to the permissions that were granted.

5. Data Retention

Operational logs and technical records are generally retained for up to 30 days unless a longer period is required for security, troubleshooting, fraud prevention, legal obligations, or compliance purposes. Data that is no longer needed is deleted or anonymized.

6. Data Sharing

  • Data is not sold.
  • Data is not shared with third parties for advertising purposes.

Data may be disclosed only if required by law or to protect the rights and safety of users and the App.

7. Data Security

We take reasonable technical and organizational measures to protect the information the App processes, including limiting access to authorized personnel, protecting access tokens, and transmitting data over secure connections. However, no method of transmission or storage is completely secure, and we cannot guarantee absolute security.
